# Quizly

Веб-приложение для создания и изучения флеш-карточек.


- **[Предметная область]**
  это веб-приложение для эффективного обучения с помощью метода флеш-карточек (flashcards). 
Пользователи могут создавать тематические наборы карточек, где каждая карточка
содержит термин (вопрос) и его определение (ответ).
Приложение помогает запоминать информацию методом активного воспроизведения 
— пользователь видит термин, пытается вспомнить определение, а затем проверяет себя.
- **[Пользовательские сценарии]**
## Пользователи и сценарии
### Студент
**Цель:** найти готовый набор и начать его изучать.

- **Главная страница** — открывает `/`, видит ссылку на каталог.
- **Список наборов** — переходит на `/sets`, видит все доступные наборы с названием, описанием и количеством карточек.
- **Некорректный адрес** — вводит несуществующий адрес, получает HTTP 404.

### Преподаватель
**Цель:** создать набор карточек и поделиться им со студентами.

- **Создание набора** — формирует новый набор с карточками.
- **Редактирование набора** — добавляет/изменяет карточки в своём наборе.
